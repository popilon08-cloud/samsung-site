ההגדרה צעד אחר צעד

הדוגמה היא נתב הקצה של לונדון מול R-ISP-1.

  1. בודקים שהקו לספק עובד: ping 10.0.0.21. ‏BGP רץ מעל TCP, ובלי קישוריות לכתובת של השכן השכנות לא עולה.
  2. מגדירים נתיב Default סטטי לספק: ip route 0.0.0.0 0.0.0.0 10.0.0.21.
  3. נכנסים ל-router bgp 65001, שהוא מספר ה-AS של הרשת הפנימית.
  4. מגדירים את השכן עם הכתובת שלו ומספר ה-AS שלו: neighbor 10.0.0.21 remote-as 100.
  5. מפרסמים את רשת הסניף: network 192.168.64.0 mask 255.255.192.0. הפקודה עובדת רק אם בטבלת הניתוב יש נתיב עם אותה רשת ואותה מסכה בדיוק. כאן זה הנתיב הסטטי ל-MLS.
  6. מפרסמים את שאר הרשתות הפנימיות: redistribute ospf 1 match internal external 1 external 2. בטוקיו ובסוון הפקודה היא redistribute eigrp 20.
  7. לכיוון פנים מפרסמים רק נתיב Default: ב-OSPF עם default-information originate, וב-EIGRP עם redistribute static.
  8. בצד של הספק מגדירים את אותה שכנות מהכיוון ההפוך. ב-R-ISP-1: ‏neighbor 10.0.0.22 remote-as 65001.
  9. בסן חוזה, שמחובר לשני ספקים, מגדירים שני שכנים ושני נתיבי Default, והשני עם AD 10.
  10. שומרים בשני הצדדים עם write memory.
