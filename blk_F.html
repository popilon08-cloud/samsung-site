בדיקת EIGRP בפקודות show

show ip protocols מציגה את ההגדרות של תהליך ה-EIGRP כמו שהנתב מבין אותן. ב-R-AS-1 רואים את משקלי המדד (K1=1, K3=1, כלומר רק רוחב פס והשהיה), את "maximum metric variance 2" שהגדרתי, את ארבע הרשתות שבפקודות network, ואת השכנים שמהם מגיע מידע. בשורה האחרונה מופיע ה-AD: ‏90 לנתיבים פנימיים ו-170 לחיצוניים.

show ip protocols ב-R-AS-1: ‏variance 2, ארבע רשתות ושלושה מקורות מידע

show ip eigrp interfaces מציגה על אילו ממשקים EIGRP פעיל וכמה שכנים יש בכל אחד (עמודת Peers). ב-R-AS-1 יש ארבעה ממשקים פעילים, ובכל אחד שכן אחד: ‏Fa4/0 ל-R-REDIST, ‏Fa0/0 לטוקיו, ‏Fa1/0 ל-R-AS-2 ו-Se2/0 ל-R-AS-3. ממשק שמופיע עם 0 שכנים הוא סימן לבעיה בצד השני.

show ip eigrp interfaces ב-R-AS-1: ארבעה ממשקים, ובכל אחד שכן אחד

show ip route eigrp מציגה רק את הנתיבים שנלמדו ב-EIGRP. יש בה שני סוגים: ‏D לנתיבים מתוך EIGRP 20 עצמו (AD 90), למשל הקישורים בריבוע של אסיה, ו-D EX לנתיבים שנכנסו מבחוץ ב-Redistribution (AD 170), למשל כל רשתות ה-OSPF שמגיעות דרך R-REDIST ‏(10.0.0.70). ה-AD הגבוה של D EX מבטיח שאם אותה רשת תגיע גם מבפנים, הנתיב הפנימי ייבחר.

show ip route eigrp ב-R-AS-1 (1): נתיבי D EX דרך R-REDIST ונתיבי D מתוך אסיה

show ip route eigrp ב-R-AS-1 (2): כל קישורי ה-OSPF מגיעים כ-D EX עם אותו מדד שהוגדר ב-Redistribution
