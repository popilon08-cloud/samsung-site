ההגדרה צעד אחר צעד

הסדר שבו הגדרתי את ההגנות בכל סניף מורכב. הדוגמה היא מסוון, ובשאר הסניפים משתנים רק מספרי ה-VLAN והפורטים. הסדר חשוב: קודם העץ של STP והערוץ בין הליבות, ורק אחר כך ההגנות על הפורטים של המחשבים.

שלב 1: Rapid-PVST ובחירת השורש

בכל מתג בסניף מפעילים Rapid-PVST. בליבה הראשית קובעים שורש ראשי ל-VLAN המשותפים, בליבה השנייה שורש גיבוי, וב-MLS של כל מחלקה שורש ל-VLAN שלה:

CORE1(config)# spanning-tree mode rapid-pvst
CORE1(config)# spanning-tree vlan 1,10 root primary

CORE2(config)# spanning-tree mode rapid-pvst
CORE2(config)# spanning-tree vlan 1,10 root secondary

MLS-PROD(config)# spanning-tree mode rapid-pvst
MLS-PROD(config)# spanning-tree vlan 20 root primary

root primary קובע עדיפות 24576, ו-root secondary קובע 28672. במתגי הגישה מספיקה השורה spanning-tree mode rapid-pvst.

שלב 2: EtherChannel בין הליבות

מגדירים את אותן פקודות בשתי הליבות, על הפורטים שמחברים ביניהן. את ה-Trunk מגדירים על ה-Port-channel, ולא על כל פורט בנפרד:

CORE1(config)# interface range GigabitEthernet0/1 , GigabitEthernet1/1
CORE1(config-if-range)# channel-group 1 mode active
CORE1(config-if-range)# exit
CORE1(config)# interface Port-channel1
CORE1(config-if)# description TO-CORE2
CORE1(config-if)# switchport mode trunk

mode active מפעיל LACP. הערוץ עולה רק כששני הצדדים מוגדרים, ולכן אחרי הליבה הראשונה הוא עדיין למטה.

שלב 3: DHCP Snooping במתג הגישה

קודם מסמנים את ה-Uplink כמהימן, ורק אז מפעילים את ההגנה. אם מפעילים בסדר הפוך, התשובות של שרת ה-DHCP נזרקות עד שמגיעים לפקודת ה-trust:

ACC(config)# interface GigabitEthernet0/1
ACC(config-if)# ip dhcp snooping trust
ACC(config-if)# exit
ACC(config)# ip dhcp snooping
ACC(config)# ip dhcp snooping vlan 20,30,40,50
ACC(config)# no ip dhcp snooping information option

שלב 4: הפורטים של המחשבים

על כל הפורטים שמחוברים אליהם מחשבים מגדירים יחד Port Security, הגבלת קצב ל-DHCP, ‏PortFast ו-BPDU Guard. השורה switchport mode access חייבת לבוא ראשונה, כי Port Security לא מופעל על פורט שלא הוגדר כ-access:

ACC(config)# interface range FastEthernet0/1 - 4
ACC(config-if-range)# switchport mode access
ACC(config-if-range)# switchport port-security
ACC(config-if-range)# switchport port-security maximum 1
ACC(config-if-range)# switchport port-security mac-address sticky
ACC(config-if-range)# switchport port-security violation shutdown
ACC(config-if-range)# ip dhcp snooping limit rate 10
ACC(config-if-range)# spanning-tree portfast
ACC(config-if-range)# spanning-tree bpduguard enable

בפורט שיש בו טלפון IP ומחשב קובעים maximum 2, ובפורט של נקודת גישה אלחוטית maximum 10 עם violation restrict.

שלב 5: פורטים שלא בשימוש

ACC(config)# vlan 999
ACC(config-vlan)# name UNUSED
ACC(config-vlan)# exit
ACC(config)# interface range FastEthernet0/5 - 24 , GigabitEthernet0/2
ACC(config-if-range)# switchport access vlan 999
ACC(config-if-range)# shutdown

לפני השלב הזה בודקים ב-show interfaces status אילו פורטים באמת מחוברים, כדי לא לכבות פורט של מחשב.
