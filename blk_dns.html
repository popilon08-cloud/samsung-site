צעד אחר צעד:

  1. בשרת, בלשונית Config, נותנים כתובת קבועה, מסכה ושער לפי תוכנית הכתובות של חדר השרתים.
  2. בלשונית Services בוחרים DNS ומעבירים את DNS Service ל-On.
  3. בשדה Name כותבים את השם המלא (למשל mail.samsung-lon.com), ב-Type בוחרים A Record (בבנגלור AAAA Record), וב-Address את כתובת השרת. לוחצים Add.
  4. חוזרים על שלב 3 לכל שם בטבלה שלמטה.
  5. בשרת ה-DHCP בודקים שבכל מאגר השדה DNS Server הוא הכתובת של שרת ה-DNS. כך כל מחשב יודע את מי לשאול.
  6. בדיקה ממחשב, ב-Command Prompt: ‏nslookup www.samsung-lon.com מחזיר את הכתובת, ו-ping לפי שם מצליח.
