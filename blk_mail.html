צעד אחר צעד:

  1. בשרת הדואר: Services, ואז EMAIL. מעבירים את SMTP Service ואת POP3 Service ל-On.
  2. בשדה Domain Name כותבים את הדומיין של הסניף (למשל samsung-lon.com) ולוחצים Set.
  3. לכל חשבון כותבים User ו-Password ולוחצים על +. החשבון מופיע ברשימה.
  4. בשרת ה-DNS מוסיפים רשומה בשם mail עם הכתובת של שרת הדואר.
  5. במחשב: Desktop, ואז Email. ממלאים Your Name, ‏Email Address (למשל fin1@samsung-lon.com), ‏Incoming Mail Server ו-Outgoing Mail Server (שניהם mail.samsung-lon.com), ‏User Name ו-Password, ולוחצים Save.
  6. בדיקה: Compose, כותבים כתובת של חשבון במחלקה אחרת ולוחצים Send. בשורת הסטטוס צריך להופיע Send Success. במחשב של הנמען לוחצים Receive, וההודעה מופיעה עם Receive Mail Success.
