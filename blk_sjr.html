צעד אחר צעד:

  1. בכל אחד משני הנתבים יוצרים תת-ממשק Gi2/0.130, עם encapsulation dot1Q 130 וכתובת מהרשת 172.17.130.0/24. כך הנתב נכנס ל-VLAN 130 בלי לשנות אף מתג.
  2. ב-MLS-SRV ובשני הנתבים מגדירים router ospf 1, עם router-id ועם network 172.17.130.0 0.0.0.255 area 0.
  3. ב-MLS-SRV מוסיפים redistribute static subnets, שמפרסם לנתבים את רשתות המחלקות.
  4. ב-R-EDGE-2 מגדירים כתובות על הקווים לספקים, ואז שני נתיבי Default: הראשי דרך ISP-1, והגיבוי דרך ISP-2 עם AD 10.
  5. ב-R-EDGE-2 מוסיפים ל-OSPF את default-information originate, כדי שכל הסניף ילמד את היציאה.
  6. ב-R-EDGE-2 מגדירים router bgp 65003 עם שני השכנים, ועם redistribute ospf 1 match internal external 1 external 2.
  7. בדיקה: show ip ospf neighbor ב-MLS-SRV, ‏show ip bgp summary ב-R-EDGE-2, ו-ping משרת בסניף ל-8.8.8.8.
  8. שומרים בשלושת הרכיבים עם write memory.
