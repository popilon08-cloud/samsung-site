ההגדרה צעד אחר צעד

כך הגדרתי כל קישור WAN, מהכבל ועד הבדיקה. הדוגמה היא הקו הטורי בין R-BB-1 ל-R-EU-1, ברשת 10.0.1.0/30.

  1. מחברים את הכבל לפי טבלת החיבורים. בקו Serial בוחרים כבל Serial DCE, והנתב שלוחצים עליו ראשון הוא צד ה-DCE.
  2. בנתב חדש עונים no לשאלת ההגדרה הראשונית, ואז enable ו-configure terminal.
  3. נותנים שם עם hostname, ומבטלים חיפוש DNS עם no ip domain-lookup.
  4. יוצרים interface Loopback0 עם כתובת במסכה 255.255.255.255. הכתובת הזאת תשמש אחר כך Router-ID.
  5. נכנסים לממשק של הקישור וכותבים description שאומר לאן הוא מחובר, ואז ip address עם המסכה 255.255.255.252.
  6. בצד ה-DCE של קו Serial מוסיפים clock rate 64000. בלי השעון הקו נשאר למטה.
  7. מפעילים את הממשק עם no shutdown.
  8. חוזרים על שלבים 5 ו-7 בנתב שבצד השני, עם הכתובת השנייה של אותה רשת, ובלי clock rate.
  9. שומרים עם write memory, ומשנים את שם התצוגה בלשונית Config.
! R-BB-1 (DCE)
interface Serial2/0
 description WAN TO R-EU-1 Se2/0 (DCE)
 ip address 10.0.1.1 255.255.255.252
 clock rate 64000
 no shutdown

! R-EU-1
interface Serial2/0
 ip address 10.0.1.2 255.255.255.252
 no shutdown
