צעד אחר צעד:

  1. מזהים בנתב את הממשק שפונה לסניף (inside) ואת הממשק שפונה לספק (outside), לפי טבלת התכנון.
  2. כותבים את access-list 110: קודם שלוש שורות deny לשלושת הטווחים הפרטיים, ובסוף שורת permit לרשת הסניף. הסדר חשוב, כי הרשימה נבדקת מלמעלה למטה.
  3. בממשק הפנימי כותבים ip nat inside, ובממשק לספק ip nat outside.
  4. מחברים את הכול בשורה אחת: ip nat inside source list 110 interface Serial0/3/0 overload. המילה overload היא מה שהופך את התרגום ל-PAT.
  5. בתל אביב בלבד מוסיפים את שורת ה-Port Forwarding: ‏ip nat inside source static tcp, עם הכתובת והפורט הפנימיים ואחריהם החיצוניים.
  6. בדיקה: ping ל-8.8.8.8 ממחשב בסניף, ומיד אחריו show ip nat translations בנתב. צריכה להופיע שורה עם הכתובת של הקו לספק כ-Inside Global.
  7. בדיקה הפוכה: ping לסניף אחר. בטבלת התרגומים לא צריכה להופיע שורה חדשה.
  8. שומרים עם write memory. אחרי שינוי של תרגום קבוע ב-Packet Tracer שומרים גם את הקובץ ופותחים אותו מחדש לפני הבדיקה.
