ההגדרה צעד אחר צעד

הסדר שבו הגדרתי ACL לכל מחלקה. הדוגמה היא MKT בטוקיו, שהרשת שלה 192.168.130.0/24.

שלב 1: רשימת הרשתות

לפני שכותבים פקודה אחת, רושמים מהי רשת המקור (המחלקה שעליה מגינים) ומהן הרשתות של שאר המחלקות. ה-Wildcard הוא ההפך של המסכה: לרשת ‎/24 הוא 0.0.0.255.

שלב 2: יצירת ה-ACL

נכנסים למתג או לנתב שמשמש שער של המחלקה, ויוצרים ACL מורחב עם שם. שורת deny לכל מחלקה אחרת, ובסוף permit לכל השאר. הסדר קובע: הנתב עוצר בשורה הראשונה שמתאימה, ולכן permit ip any any חייב להיות אחרון.

JPN_Samsung_F1-MLS(config)# ip access-list extended MKT-IN
JPN_Samsung_F1-MLS(config-ext-nacl)# deny ip 192.168.130.0 0.0.0.255 192.168.140.0 0.0.0.255
JPN_Samsung_F1-MLS(config-ext-nacl)# deny ip 192.168.130.0 0.0.0.255 192.168.150.0 0.0.0.255
JPN_Samsung_F1-MLS(config-ext-nacl)# deny ip 192.168.130.0 0.0.0.255 192.168.160.0 0.0.0.255
JPN_Samsung_F1-MLS(config-ext-nacl)# permit ip any any
JPN_Samsung_F1-MLS(config-ext-nacl)# exit

שלב 3: הצמדה לשער של המחלקה

ACL שלא הוצמד לממשק לא עושה כלום. מצמידים אותו ל-SVI של המחלקה בכיוון in:

JPN_Samsung_F1-MLS(config)# interface Vlan130
JPN_Samsung_F1-MLS(config-if)# ip access-group MKT-IN in
JPN_Samsung_F1-MLS(config-if)# end
JPN_Samsung_F1-MLS# write memory

שלב 4: שאר המחלקות

חוזרים על שלבים 2 ו-3 לכל מחלקה, עם השם שלה, רשת המקור שלה וה-SVI שלה. בסוון ובסן חוזה כל ACL מוגדר ב-MLS של המחלקה שלו.

שלב 5: ב-IPv6 (בנגלור)

אותו רעיון, עם שלושה הבדלים: הפקודה ipv6 access-list, רשתות עם Prefix במקום Wildcard, והצמדה עם ipv6 traffic-filter על תת-הממשק של המחלקה בנתב:

IND_Samsung_F0-R-1(config)# ipv6 access-list DEV-IN
IND_Samsung_F0-R-1(config-ipv6-acl)# deny ipv6 2001:DB8:3:20::/64 2001:DB8:3:30::/64
IND_Samsung_F0-R-1(config-ipv6-acl)# deny ipv6 2001:DB8:3:20::/64 2001:DB8:3:40::/64
IND_Samsung_F0-R-1(config-ipv6-acl)# deny ipv6 2001:DB8:3:20::/64 2001:DB8:3:50::/64
IND_Samsung_F0-R-1(config-ipv6-acl)# permit ipv6 any any
IND_Samsung_F0-R-1(config-ipv6-acl)# exit
IND_Samsung_F0-R-1(config)# interface GigabitEthernet0/0/0.20
IND_Samsung_F0-R-1(config-subif)# ipv6 traffic-filter DEV-IN in

שלב 6: בדיקה

  1. ping ממחשב במחלקה למחשב במחלקה אחרת: צריך להיכשל.
  2. ping מאותו מחשב לשרת: צריך להצליח.
  3. show access-lists במתג: ליד שורת ה-deny מופיע מספר ההתאמות (matches), והוא עולה אחרי ה-ping שנחסם.
